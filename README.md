# blender-scene-graph-organizer

A Blender add-on for batch renaming, auto-parenting, hierarchy flattening, naming validation, and batch export.

## Stack

Primary language: **Python**

## Project structure

- `__init__.py` — Automate scene cleanup and standardization for rendering or game export.
- `properties.py` — addon settings
- `core_logic.py` — pure functions
- `operators.py` — blender operators
- `ui_panels.py` — ui panels
- `utils.py` — helpers
- `export_handler.py` — export logic
- `validation.py` — regex validation

## Usage

Review the source files and install any dependencies referenced by the project before running it.
